
## Added: Code Reader

- New standalone route: `/code-reader`.
- Separate landing entry for AI code generation (`/studio`) and code reading/editing (`/code-reader`).
- Open one or more local source files with the device file picker.
- Automatic language detection from file extension.
- Expanded language list for common web, backend, mobile, scripting, data, and markup files.
- Edit, save to the workspace, copy, and download source files.
- Files are shared with the existing SAID workspace through the same Zustand store.
- Lightweight in-app syntax coloring without adding a large editor dependency.
